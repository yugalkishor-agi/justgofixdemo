FONT STRATEGY
=========================================================

Do NOT use one font everywhere.

Instead create a professional typography system.

Choose fonts according to their personality.

Examples:

Khand
→ Strong headings
→ Political slogans
→ Statistics
→ Hero highlights

Technor
→ Premium hero headlines
→ Campaign titles
→ Large editorial typography

Satoshi
→ Body text
→ Navigation
→ Paragraphs
→ Buttons
→ Cards
→ Forms
→ Small labels

Panchang
→ Small accent titles
→ Numbers
→ Campaign tags
→ Decorative headings
→ Highlight words (only where appropriate)

These are suggestions.

Study the fonts carefully and decide where each font naturally fits.

Use them intentionally.

Never use fonts randomly.

DESIGN IMPROVEMENTS
=========================================================

Improve the existing design without changing its identity.

Focus on:

• Better spacing
• Better proportions
• Better rhythm
• Better typography
• Better image treatment
• Better CTA hierarchy
• Better cards
• Better section transitions
• Better visual balance

Don't redesign just for the sake of redesign.

=========================================================
DESIGN PHILOSOPHY
=========================================================

Think like a professional design reviewer.

Ask yourself before every change:

Does this improve readability?

Does this improve hierarchy?

Does this improve storytelling?

Does this improve credibility?

Does this improve accessibility?

If the answer is NO,

leave it unchanged.

LICENSE
=========================================================

The fonts include their own license files.

Review the licenses.

If attribution or license information is required by the license terms, create an appropriate acknowledgements section in the website footer or another suitable location.

=========================================================
FINAL GOAL
=========================================================

The final website should feel professionally art-directed.

Typography should immediately communicate trust, authority, and emotion.

The interface should feel intentionally designed—not AI-generated.

Every font choice, every spacing adjustment, and every visual refinement must have a clear design rationale.

Never prioritize decoration over clarity.

Think like a Creative Director preparing the final version for a public launch.
